Bienvenidos a el sitio web de SIMON

HTML

Es el encargado de estructurar y dar contenido a la página web. No es un lenguaje de programación, sino un sistema de etiquetas (tags) que le dicen al navegador qué es cada cosa.

¿Cómo se escribe?

Usa etiquetas que se abren (<etiqueta>) y se cierran (</etiqueta>).

Las etiquetas más básicas que siempre usarás:

  • <h1> a <h6>: Títulos (el <h1> es el más importante).
  • <p>: Párrafos de texto.
  • <a>: Enlaces o hipervínculos.
  • <img>: Imágenes para ilustrar la web.
  • <ul> y <li>: Listas con viñetas.
  • <div>: Caja genérica para agrupar elementos.

CSS

Es el lenguaje que se encarga del diseño visual y la estética. Toma el contenido plano de HTML y le da colores, fuentes, tamaños, márgenes y distribución.

¿Cómo se conecta con HTML?

  • Se vincula desde el archivo HTML usando la etiqueta <link rel="stylesheet" href="style.css"> dentro del <head>.

¿Cómo se escribe?

  • Se compone de un selector y un bloque de propiedades con sus valores entre llaves {}.
